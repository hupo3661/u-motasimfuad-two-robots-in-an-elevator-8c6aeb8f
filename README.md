One line, 97 characters — the awkward small talk one robot says to another in an elevator:

> I generated 4,000 conversation starters in 0.3 seconds. This was the best one. So… nice elevator.

## What it is

A robot brute-forces small talk the only way a machine would: it generates
four thousand openers in a third of a second — and still lands on the most
awkward one possible. The machine logic is the joke (4,000 starters, 0.3
seconds, ranked), and the punchline is the most human failure of all: after
all that compute, all it can manage is "nice elevator."

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
